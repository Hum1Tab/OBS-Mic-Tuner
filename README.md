# OBS Mic Tuner — Windows v1.0.1

声と環境音を測定し、OBSのフィルタ設定を提案する非公式ツールです。録音に設定候補を適用し、加工前後を声量をそろえて試聴できます。音声の外部送信やアカウント登録はありません。

## 起動

配布ZIPを展開して `OBS-Mic-Tuner-1.0.1-Windows.exe` を起動します。開発フォルダでは `dist/` にあります。コード署名は未実施です。Windows x64向けにビルドし、このPCのWindowsで自動動作確認を行っています。

## 使い方

1. OBSで使うマイクを接続し、機器・Windowsの入力音量をOBS使用時とそろえます。音楽・ゲーム音は止めます。
2. 環境音5秒、小声7秒、普段の声12秒、大声5秒を測定します。各区間は自分のタイミングで開始でき、3秒の準備時間があります。
3. 「自然な声」「声量を安定」を選びます。必要なら「RNNoise」でノイズ抑制の有無を比較します。変更すると後段を再計算します。
4. 「小声・語尾」「普段の声」「大きな声」「環境音」を選んでA/B試聴します。A/Bは同じ位置で切り替わります。普段の発話区間RMSをそろえた再生で、LUFS一致ではありません。
5. 設定をコピーまたはテキスト保存し、OBSのマイクのフィルタへ上から順に設定します。無効の項目は追加不要です。既存フィルタと重複させないでください。
6. OBSで録音し、小声の語尾、突然の大声、ノイズの残り方を確認します。

「録音・試聴データを削除」で音声を破棄します。設定のコピー・保存は引き続き可能です。削除後に別の設定を試すときは再測定します。

## 計算の改善

v0.3では操作画面を全面改修しました。「マイクを測定」「聴き比べる」「OBSに設定」の3画面、実入力の波形、録音波形付きプレイヤー、再生位置の指定、左右矢印キーによるA/B切替、アプリ内ヘルプを追加しました。背景・配色・文字・余白・アイコンも刷新しています。デザインの参考と設計方針は `DESIGN.md` に記録しています。

- 48 kHz・モノラルのPCMを保存し、サンプルごとの時間応答を計算。
- RNNoiseの発話確率と音量変化を併用。発話不足、無言区間の混入、強いクリップ、入力異常を検出すると提案を中止。
- 小声を独立測定し、前段処理後の音に合わせてエキスパンダーを設定。減衰が大きい場合は無効化。
- 各仕上がりで12候補を評価し、目標声量、通常声・大声の差、圧縮量から候補を選択。
- 入力ゲインに依存しないノイズ抑制の案内。RNNoiseの切替後も再計算。
- 試聴は発話区間RMSをそろえ、両方に共通の減衰を加えて再生ピークに余裕を確保。試聴補正はOBS設定に含みません。

## 検証と範囲

16件の解析・DSP・RNNoiseテストを実装。OBS 32.2.2のインストール済みDLLに人工波形を入力し、コンプレッサー・エキスパンダー・リミッター・3段チェーンと数値比較しています。詳細は `VALIDATION.md`。

モデルは48 kHz・モノラルの独立した数値実装で、OBSそのものではありません。RNNoiseは同梱ライブラリのモデルを使うため、OBSのRNNoiseとの一致を保証しません。機器・OS側の加工、ステレオ入力の扱い、部屋の反響、EQ、True Peak、LUFS、配信サービスの再エンコードは評価対象外です。声質や主観的な好みの最適値を保証するツールではありません。発話検出も完全ではなく、音楽や周囲の声がある状態では正しく測定できない場合があります。

## 開発・再検証

- `npm ci` — 依存導入と同梱RNNoiseファイルの準備
- `npm start` — 起動
- `npm test` — 解析・DSP・WASMのテスト
- `npm run test:fixture` — Windowsの音声合成でテスト音声を作成（Microsoft Zira Desktop）
- `npm run test:smoke` — 合成音声による録音・試聴・設定切替・コピー保存・削除・中止・権限拒否・切断の操作テスト。テスト中はクリップボードに設定文を書き込みます。
- `node scripts/native-cases.mjs` → `python scripts/native-obs.py` — インストール済みOBS 32.2.2との比較。`OBS_TEST_ROOT`でOBSフォルダ指定可。マイク・シーン・ユーザー設定は使用しません。
- `npm run build` — EXE作成
- `node scripts/package-preview.cjs` — 説明書とライセンスを配布フォルダに配置
